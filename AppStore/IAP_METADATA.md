## Instructies App Store Connect
1. Ga naar appstoreconnect.apple.com
2. Dicom Player → In-App Purchases
3. Per product:
   - Display Name → zie boven
   - Description → zie boven
   - Promotional image → upload bijbehorende PNG uit AppStore/
4. Controleer: geen €-tekens in naam of beschrijving
5. Sla op → opnieuw indienen
