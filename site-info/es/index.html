¿Qué hace la app?

  • Visor a pantalla completa: pellizca para ampliar, arrastra, doble toque para reiniciar
  • Reproductor cine — estudios multiframe como vídeo fluido
  • Ajustes Window/Level para abdomen, pulmón, hueso y cerebro
  • Navegador de series — cortes agrupados automáticamente por serie
  • Abre .dcm desde Archivos, AirDrop o correo — analizador integrado, sin internet
  • Exporta cada fotograma como PNG o JPEG; tema oscuro
